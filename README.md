# ADHD & Sex Prediction — WiDS Datathon 2025

This repository features our team’s competitive submission for the **WiDS (Women in Data Science) Datathon 2025**, developed as part of our Machine Learning coursework. 

## Overview
This project delivers a robust, end-to-end machine learning and deep learning pipeline designed to address complex clinical classification tasks. The workflow emphasizes rigorous data hygiene, advanced feature engineering, multi-model experimentation, and thorough performance evaluation.

## Tech Stack
* **Language:** Python (v3.10.12)
* **Data Processing & Analysis:** Pandas, NumPy, Scikit-Learn (`StandardScaler`, `PCA`), SciPy
* **Machine Learning & Boosting:** Scikit-Learn (`RandomForestClassifier`, `MultiOutputClassifier`), XGBoost
* **Deep Learning:** PyTorch (`nn`, `TensorDataset`, `DataLoader`)
* **Graph & Spatial Analysis:** NetworkX
* **Visualization:** Matplotlib, Seaborn
