# ADHD & Sex Prediction — WiDS Datathon 2025

This repository features our team’s competitive submission for the **WiDS (Women in Data Science) Datathon 2025**, developed as part of our Machine Learning coursework[cite: 1]. 

## Overview
This project delivers a robust, end-to-end machine learning and deep learning pipeline designed to address complex clinical classification tasks[cite: 1]. The workflow emphasizes rigorous data hygiene, advanced feature engineering, multi-model experimentation, and thorough performance evaluation[cite: 1].

## Tech Stack
* **Language:** Python (v3.10.12)[cite: 1]
* **Data Processing & Analysis:** Pandas, NumPy, Scikit-Learn (`StandardScaler`, `PCA`), SciPy[cite: 1]
* **Machine Learning & Boosting:** Scikit-Learn (`RandomForestClassifier`, `MultiOutputClassifier`), XGBoost[cite: 1]
* **Deep Learning:** PyTorch (`nn`, `TensorDataset`, `DataLoader`)[cite: 1]
* **Graph & Spatial Analysis:** NetworkX[cite: 1]
* **Visualization:** Matplotlib, Seaborn[cite: 1]
